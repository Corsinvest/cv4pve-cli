The <AliasCount /> built-in aliases, read from the catalog in the code this site was built from. How to
use them is on the [Aliases](/cv4pve-cli/aliases/) page; `cv4pve-cli alias list -v` prints the names,
descriptions and API calls in the terminal, together with your own aliases.

- **Arguments** are given in order after the alias name. *or `--guest`* marks the aliases that take
  `--guest <id|name>` in place of the node, the type and the VM ID.
- **`--yes`** under the name marks the aliases that list it as a confirmation — which the current
  version [does not enforce, and refuses](/cv4pve-cli/aliases/#operations-that-change-the-cluster).
- **API call** is what the alias runs, as you would write it after `cv4pve-cli api`.
